Hydrion website asset sources
=============================

The public website uses genuine owner-supplied Hydrion assets:

- Product identity: the tracked portfolio asset `assets/images/hydrion.png`, sourced from the Hydrion application artwork.
- Publisher identity: the tracked portfolio asset `assets/the1807.png`.
- App renders: `screenshots/*.png`, copied without visual alteration from the Hydrion application's local RC2 rendered acceptance audit on July 20, 2026.

The screenshot captions identify the images as development renders because they were produced after RC1 and must not be represented as captures from the published RC1 APK.
Bottle Bingo and Pomodoro Sip screenshots were not available in the verified render set; the website uses labeled pending containers rather than invented interface images.

Legacy shark-avatar copies in this directory predate the final product-page implementation and are not loaded by the public Hydrion routes.
