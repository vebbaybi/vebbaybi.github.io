Heimdall

What it is: AI-assisted content workflow and review system.

Problem solved: Helps an operator draft, review, revise, approve, and package content without turning the system into an autonomous posting bot.

Architecture: FastAPI workflow layer, in-memory review queue, template logic, export package, operator summary, manual posting pack, and test coverage around review behavior.

Stack: Python, FastAPI, pytest, ruff, mypy, in-memory review queue.

Current proof: Local repo contains workflow API, draft queue, approval/rejection/revision loop, content series templates, export package, operator summary, manual posting pack, tests, and CI configuration.
