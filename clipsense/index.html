Purpose and user

For creators facing more footage than context.

ClipSense is intended for reaction footage, gameplay captures, clip dumps, and long sessions that need a first organizational pass before editorial decisions.

Current input: ZIP upload

Current output: Clips, transcripts, tags, and basic groups

Processing: Local development stack

Engineering

A service boundary for each stage of the workflow.

The current implementation uses Next.js, Go services, Python workers, Postgres, Redis, and Qdrant through Docker Compose. These describe the present architecture, not a hosted public service.
